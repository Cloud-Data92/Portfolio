## About the logistics case studies

The [Enterprise Delivery Analytics](projects/enterprise-delivery-analytics/) project describes classes of problem I have worked on professionally in last-mile logistics analytics. To be unambiguous about what it is and is not:

**What it is** — original SQL I wrote for this repository, against schemas I invented for it, demonstrating industry-standard analytical techniques (window functions, dimensional modeling, geospatial predicates, incremental merge patterns) applied to well-known categories of logistics problem: capacity utilization, service-area coverage, delivery reliability, and data reconciliation.

**What it is not** — it is not my employer's code. No production query, script, schema, configuration, or dataset has been copied, transcribed, or reproduced here. Nothing in this repository was taken from any employer system.

Accordingly, this project contains no:

- employer, project, dataset, table, column, or system identifiers from any production environment
- customer, order, route, carrier, store, associate, or financial records — every value shown is synthetic and generated by the scripts committed alongside it
- capacity thresholds, business rules, pricing, contract terms, or configuration values from any internal system
- internal program names, screenshots, documents, or other non-public material

The techniques demonstrated are general industry practice, documented in public vendor documentation and standard data-warehousing literature. The business problems are described at the level of the industry, not any single company.
